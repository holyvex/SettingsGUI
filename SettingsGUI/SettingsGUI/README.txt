SettingsGUI - build instructions
================================
Option A (Windows): install JDK 21 (adoptium.net) + Maven, then double-click build.bat
Option B (Mac/Linux): ./build.sh
Option C (no installs): upload this folder to a GitHub repo -> Actions tab -> "Build plugin"
  -> download the "SettingsGUI-jar" artifact.
Result: target/SettingsGUI-1.0.0.jar  -> put in your server's plugins folder (Paper 1.21.11).
